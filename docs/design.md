# Interface implementation

The product is a work surface for reviewing language data and measured ML experiments. A language steward uses it in an ordinarily lit office or community workspace, reading detailed tables and checking source records. The interface uses a light, low-glare neutral canvas, a slightly darker navigation surface and a restrained green accent for actions and states.

System typography, predictable left navigation, accessible native form controls, semantic tables and progressive disclosure keep the workflow familiar. Original rows and proposed transformations are inspectable before source approval. Empty states explain the next step without adding invented datasets or metrics. Training logs and evaluation cells render only API observations. Experimental and test-only models are labelled explicitly.

Mobile navigation scrolls horizontally, the sidebar becomes a compact header, forms and comparisons stack, and long tables remain horizontally scrollable. Focus indicators, labelled controls, a skip link, live error/log regions and reduced-motion handling are included. No decorative cultural motifs or invented Indigenous vocabulary are used.
